# Trabajo pendiente

`plans` contiene propuestas, desarrollos parciales y comprobaciones todavía abiertas.
Las reglas ya implementadas están en las [premisas de la plantilla](../architecture/premisas-de-la-plantilla.md)
y sus fuentes completas. El [auditor documental](../guides/auditar-documentacion.md) fija cuándo
consolidar y retirar un plan; su antigüedad o una casilla sin marcar no deciden su estado.
