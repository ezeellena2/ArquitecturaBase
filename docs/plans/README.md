# Trabajo pendiente

`plans` contiene propuestas, desarrollos parciales y comprobaciones todavía abiertas.
Las reglas ya implementadas están en las [premisas de la plantilla](../architecture/premisas-de-la-plantilla.md)
y sus fuentes completas. El [auditor documental](../guides/auditar-documentacion.md) fija cuándo
consolidar y retirar un plan; su antigüedad o una casilla sin marcar no deciden su estado.

| Conexión a bases de datos de clientes | **Pendiente de decisión del usuario** (2026-10-22). Para traer datos de un sistema externo (por ejemplo, Macrosistemas de OCHA), para catálogos y a futuro para tableros. Se descartaron un conector propio y Azure Data Factory por complejos. La opción propuesta es una VPN de sitio a sitio de Azure a la red del cliente, con un usuario de solo lectura; «Conexiones externas» en Administración; y un catálogo «Desde una base externa» que elige tabla o vista y mapea columnas sin escribir SQL. Requiere un ADR que amplíe el 0019 a bases externas y que el ambiente de Azure corra dentro de una red virtual. Contexto en la [hoja de ruta de catálogos](2026-10-21-catalogos-con-origenes-externos.md#conectividad-el-servidor-del-cliente-o-azure). |
