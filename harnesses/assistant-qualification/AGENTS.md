# Assistant qualification harness

Development-only console outside the solution. Manual invocation; default/--list must not load secrets, DI, databases or a provider. --live is explicit and uses an isolated fictitious database and the existing protected OpenAI connection read-only through the real reader. No direct transports, Unprotect, reflection or another coordinator/worker. Preserve the actual engine's quota, fence, uncertainty and retention behavior.

Never emit prompt/question/answer/result/proposal/ciphertext/token/connection strings. Export only the closed safe evidence DTO and hashes of public fixtures/instructions/schema/profile. A candidate is not a qualified production profile. Do not write production configuration automatically.

Use source AGENTS and docs/guides/configurar-ia.md, ADR0020 and the Etapa5 plan. Run TDD for harness rules before real calls. Register this folder in the instruction map when promoting these drafts. CLAUDE.md imports this file. Do not reference this harness from product src or the solution.

Audio cases use four committed fictitious Ogg/Wav fixtures (es/en), the same saved OpenAI connection and real IAssistantOperations NormalizeAudio purpose. The isolated host replaces only private file storage with durable local WriteOnce files under its output; it never calls a provider directly or converts a failed Ogg probe automatically. Read-only audio actors have neither Send nor Home. Resume rebuilds the closed channel context from safe ledger identity/scope and only calls Get. Stop on the first failed mechanical check; keep semantic review pending and never export transcripts or their hashes.

QualificationFormSeed owns fictitious form data only: real authoring/catalog/suggestion/capture services and the real local compiler, with BF publication facts written through Domain factories in the isolated database. The local-visit fallback uses a real Manual catalog item without English, while the published questions stay bilingual. Completed historical sessions reference the actual capture receipt and linked subject; their terminal reviewed offers have no provider receipt, Flow JSON or Meta asset and cannot be dispatched. This fixture qualifies decisions and BF prefill, never Meta publication or delivery.

The isolated Windows host overrides only its DataProtection registration with a per-run private filesystem key ring encrypted with DPAPI. Preserve private-keys alongside the ledger for resume; never copy the app key ring, export keys or silently use plaintext on another OS. Offline checks recreate the host and verify recovery and run separation.

Audio fixture qualification compares the complete canonical token sequence in memory; only punctuation, case and diacritics are ignored. Lost negations, omitted words or translations fail. Export only fixed check IDs and booleans, never transcripts or their hashes.
